# Embed the Tw Cen MT font despite its commercial license

Full fidelity with Civilization V's UI requires its actual typeface, Tw Cen MT (a commercial Monotype font). We embed the `.ttf` in the distributed executable, knowingly accepting the redistribution-license risk. Alternatives — a free metric-compatible lookalike, or using Tw Cen MT only when found on the user's system — were offered and explicitly rejected by the project owner in favor of guaranteed fidelity. All other art is original work in the Civ5 art-deco style (game assets used as visual reference only, never shipped).
